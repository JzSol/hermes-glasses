# Test Summary - Week 36, V1.5.0

## What Was Tested

- Adam microphone conditioning, meditative cues, British voice selection,
  endpoint authentication, wake-only `Adam` handling, 30-second follow-up,
  and standalone `donzo` state transitions.
- Authenticated realtime and legacy bridge paths, including exact gate command
  routing, relay allowlisting, cooldown, unavailable/offline behavior, and
  agent bypass.
- Wireless CoreDevice selection, strict rejection of wired devices, Developer
  Mode and pairing gates, plus installed bundle version/build verification.
- Signed and unsigned `AdamVoice` device builds, and an unsigned compatibility
  build of the full `HermesGlasses` target.
- The running LaunchAgent, authenticated bridge handshake, current Hermes
  `.venv`, private STT/TTS capabilities, and local port binding.

## Test Results

- Total assertions/tests: 298
- Passed: 298
- Failed: 0
- Coverage: not collected; this repository uses focused standalone Swift and
  Python behavior suites.
- `AdamVoice` generic unsigned build: passed.
- `AdamVoice` signed iPhone build: passed as `com.vandret.adamvoice` 1.5 (10).
- `HermesGlasses` generic unsigned compatibility build: passed with two
  existing Swift concurrency/catch warnings.
- Live authenticated bridge handshake: passed with audio upload, server STT,
  streaming TTS, turn cancellation, and follow-up mode advertised.

## Key Findings

- Both “open gates” and “close gates” pulse only the configured dry-contact
  switch and bypass Hermes, so no agent confirmation is requested.
- The installer refuses USB/wired transports and will install only from a
  clean, remote-verified `main` to one paired Developer Mode iPhone.
- The Mac bridge now uses Hermes's current `.venv`; the old `venv` LaunchAgent
  paths are no longer active.

## Notes

The physical gate was not activated during automated verification. The iPhone
was still connected by USB, so the installer correctly refused to call that a
wireless install. Final wireless installation requires unplugging the cable
while the phone remains unlocked and reachable on the same local network.
